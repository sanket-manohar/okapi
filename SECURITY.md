# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's **Report a vulnerability** button on the repository's Security tab, or through the contact details at https://sanketmanohar.com/. Include the Okapi version, the platform and OS version, and steps to reproduce.

You can expect an acknowledgement within 7 days. Fixes are released as patch versions and noted in CHANGELOG.md.

Okapi never accesses or transmits user data (see PRIVACY.md). Security problems in an app that uses Okapi are the responsibility of that app's developer (see DISCLAIMER.md).
