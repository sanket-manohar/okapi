# Contributing to Okapi

Thank you for helping improve Okapi.

## Ways to help

- **Report a bug:** open an issue with the Okapi version, Flutter version, device maker and model, OS version, and the smallest code that shows the problem.
- **Report a phone-maker screen that doesn't open:** include the brand, model, OS version and the name of the screen you expected.
- **Suggest a feature:** open an issue describing the problem it solves.

## Pull requests

1. Open an issue first so we can agree on the change.
2. Fork the repository on GitHub, make your change on a branch, and open a pull request.
3. Run `dart format .`, `flutter analyze` and `flutter test` before submitting.
4. Keep changes focused and add tests where possible.
